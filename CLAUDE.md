# talent-suite

This folder is the AJMN Talent Suite sandbox prototype: one static page, index.html, with synthetic data.
Deploy it to Canvas (canvas.ajnai.net) as a static site named `talent-suite` in team `erp`.
Keep index.html exactly as it is. No database. The one backend piece allowed is server.mjs's POST /api/translate (Arabic and English translation of goals through the platform's `llm` resource); add nothing else to the server without asking.
